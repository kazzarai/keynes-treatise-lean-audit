## 備考
- folio 68「(49.1)」は第XIV章の式番号への参照で、本章の式ではない。
- folio 68–69「x, x′, x″ . . .」、folio 69 の三段論法「All P is x」等、folio 70 の A・B の報告は語・裸記号で記録しない。
- ch05-005 の印刷は狭義 < に但し書き「unless b/ah = 1」。phase6b/th_13_4 は ≤ の形のみで、狭義形・但し書きの Lean はない (所見候補)。向きの違い (and_comm) は表の備考に記した。
- B34 (2026-10-31): 上の所見候補に答えて、狭義形 phase13a_irrelevance/th_5_r005 を置いた。印刷の「unless b/ah = 1」の外にもう一つの例外 a/h = 0 があり (第II部 Ax. (iv. b) folio 136 の「unless Q = 1 or P = 0」と同じ形)、Cons (a ∧ h) を前提にするとそれは Def. VI の印刷の向きで除かれる。前提を何も足さない形は全公理を満たす有限模型で偽 (model_r005_needs_cons)。
- ch05-009, 011 (好意的証拠による増加) は第II部の定義 (favourable) の予告で、対応する定理番号は本台帳では付けていない。B43: 009 は phase15a_ch05_ch08 の定義 Favourable の本体 (定)、011 は同じ定義を前提 hh₁ に当てた展開 th_5_r011 (定; B43 修正 r1 の裁定)。phase13a_irrelevance の FavourablyRelevant (ℝ 値の PrI、前提の順 h₁h) とは別の定義で、こちらは Π の半順序の上で印刷の順 hh₁ のまま書いた。
