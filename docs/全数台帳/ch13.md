- 数え方: 定理の言明 (「(n) If A, B」) は行内なので関係式ごとに 1 本。証明の表示行は印刷の 1 行 1 本 (1 行に関係式が 2 つ以上あれば備考に「関係 n」)。証明行は補則 5–6 により「未 ((n) の証明内)」とし、Lean 対応の集計には言明行だけが入る (第 1 回の「—」を第 2 回で改めた)。「by (iv. b)」等の引用は照合語に使う。

- 第 3 回 (補則 8、細則は ch10.md ヘッダ): Lean が背景の h を足した形 (印刷 a/a・a/b・h₁/h₂・a/h₁ 等を `Pr α (α ∧ h)`・`Pr h₁ (h₂ ∧ h)` 等で述べる) は ≈ (一般形)。(4) の ≤、(5)–(7) の P, Q を `Pr α h`, `Pr β k` で書いた形、(12.1) 後件の連言の順序 (a/hx と `Pr a (x ∧ h)`) も ≈。(18) は印刷も「or」で、Lean の選言と一致する (folio 142 で確認)。
- 第 4 回 (B28b、phases/keynes_part_ii_phase10b.lean): 未だった式行 111 本 (証明行と (1.1)–(1.4)・ch13-086・ch13-129) を、その段で成り立つ関係として 1 行ずつ定理にした (担体は phase6c の KeynesI、新しい公理なし)。当てはめの細則: (a) 「A unless B」は選言 A ∨ B で書き、✓ に数える ((2)(3) の「or」と同じ扱い)。(b) 公理 (i) の但し書き `Cons …` (「… is not inconsistent」を含む) を足しただけの形は ✓ (第 3 回の「Cons h 付き」と同じ)。(c) 前件・例外だけの行 (「Since a/h = 1,」「unless b/h = 0」) は、それを前提または選言肢に持つ定理を挙げて (前提)・(例外の選言肢) と書く。(d) 印刷の前提 (a, h₂, h₁h₂ 等) を背景 h を足して書いたもの、前提の連言の順序が印刷と違うもの (hx を x ∧ h、h₂h を h ∧ h₂)、P, Q を PrI で書いたものは ≈。(e) 本公理系には前提側の置換 (公理 (ii)) も前提の連言の可換も無いので、(14)・(15)・(21) では前の行の結論の前提が次の行の仮定と順序違いになる箇所 (継ぎ目) がある。各行の定理はそれぞれ成り立つ。継ぎ目は phase10b の該当節の注釈に記した。
