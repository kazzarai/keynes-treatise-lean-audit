## 第IV部での運用細則 (補則 1〜4・6〜8 の当てはめ; ch25・ch26 はここを参照)
1. **裸記号 (補則 1)**: 1 文字の記号は、添字・プライム・バー・前置添字が付いていても裸 (`a`, `p₁`, `x₁`, `w′`, `r^{th}`)。裸記号を「X and Y」「X, Y」と並べただけのものも数えない。これらはヘッダ注記に残す。
2. **記法に数える複合表現 (補則 1)**: 関数適用 (`f(a)`, `φ₁(a)`, `S(x) . φ(x)`)、確率記号 (`a/h`, `b/ah`, `φ(x)/S(x) . h`)、並置の積 (`qE`, `cA`, `c′A′`)、冪 (`2^{r−1}`, `2^{24}`)、商 (`n/2`, `R/E`)、和記号を含む表現。数字だけの横線分数 (`1/10,000,000`, `½`, `1/10,000`) は 1 文字の記号ではなく商なので記法に数える (**裁定事項**、第 1 回から継続)。£ の金額・括弧内の数値・語で書かれた数 ("ten million", "1 in 13131") は数えない。
3. **式 (補則 2)**: 関係記号を含む表現、1 印刷行 = 1 本。行内で英語の語またはコンマで区切られた関係式は 1 本ずつ (第III部 ch20-002〜004 と同じ)。行内の等号連鎖が印刷の行をまたぐときは 1 本 (ch26-003、**裁定事項**)。
4. **参考行 (補則 3)**: 転記の都合で置く行は種別・式/記法を「参考」とし、式・記法・番号付き・Lean 対応のどの集計にも入れない。第IV部では、所見候補の置き場として 2 行 (ch25-011 Peirce の享年表、ch26-043 `(16,777,116)`) を置いた。第 1 回に記法として数えた行で補則 1 により外れるものはない (18 本すべて関数適用・確率記号・分数)。
5. **項目 ID (補則 4)**: 式行のみ。本部に (n) 番号の式はないので、項目 ID は行 ID。記法行・参考行は「—」。項目数 = 式行の項目 ID の異なり数。
6. **式行の Lean 欄 (補則 8、三段階)**: 式行は `✓`・`≈`・`✎`・`未` の 4 値のどれか一つ。行ごとの判断ではなく、補則 8 の定義で機械的に決める。
   - `✓ phase/定理名`: 印刷行の関係式が定理文 (仮定または結論) にそのまま現れる。許す差は束縛変数の名前、Lean の記法 (`Pr b (a ∧ h)` と `b/ah`、`c p w` と `c`、`w′ < w` と `w > w′`)、添字の書き方のみ。
   - `≈ phase/定理名`: 定理文が印刷行と代数的に同値な別形を述べる。本部で当たるのは、定義の代入 (`E = pA`、`q = 1 − p`、`R = qE`、`y = k log x/a` を代入した形)、分母を払った形 (`c_spec`)、結合の組み替え (`X . (Y/Z)` と `(X * Y) / Z`)、別の変数についての同値な不等式 (`q < q′` と `p′ < p`)。印刷行に現れる他の変数が、吸収された前提によって同一視されている場合 (`pA = p′A′` を `p′ = p` のもとで `p * A = p * A′` と書く) も ≈。
   - `✎ phase/定理名 (反駁 phase/定理名)`: 印刷行は反駁された (または導けない) が、修正形が定理になっている。
   - `未`: 上のどれでもない。「変数の置換で吸収されて定理文に現れない」(`p + q = 1`、`E = pA`、`q = q′`、`w = w′`、`y = k log x/a`; 補則 8 末尾の既知の裁定)、「代入値としてしか現れない」(`p = 1` を `c 1 1 = 1` で数えない、**裁定事項**)、「def がない」(`f(a) = b/(a + b)`)、「極限形 Tendsto だけ」(`b = ∞`、`f(a) = 1`、**裁定事項**)、「帰結 (単調性) だけ」は未。理由は備考に書き、Lean 欄には書かない。
   - 一つの行は一つの値。複数の定理が当たるときは、✓ > ≈ > ✎ の順に最も近いものを採り、残りは備考に書く。
7. **記法行の Lean 欄**: 補則 8 の 4 値は式行の判定なので、記法行は従来どおり `phase/定義名または定理名` (同じ表現が定義名・定理文に現れる) か `未`。理由・補助の定理名は備考。記法の Lean 対応は式の対応とは別勘定 (summary の `記法のLean対応`)。
8. **Lean 欄の表記 (補則 6)**: `✓ phase8a/keynes_F3` のように値 + phase/名前。理由を括弧で書かない。「—」は使わない。
